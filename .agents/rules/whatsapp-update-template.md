# WhatsApp Group Update Template

Whenever sending an update message to the **Indian Pixel Core team** WhatsApp group, use the following format:

```
🌐 BroadNet Website Update

Website Link: <vercel-production-url>
Version: <version in vx.x.x format>
Date: <DD-MM-YYYY>
Major Changes: <comma-separated keywords summarizing changes>

Extra Info: <brief additional context about the update>
```

## Versioning Rules
- Format: `vx.x.x` (starting from `v1.4.0`)
- **Minor change** (bugfix, font swap, small tweak): increment last digit → `v1.4.1`
- **Major change** (new pages, big feature): increment middle digit → `v1.5.0`
- **Complete overhaul**: increment first digit → `v2.0.0`

## Notes
- Use Shift+Enter for line breaks in WhatsApp Web
- Only press Enter (without Shift) at the very end to send
- Production URL: https://broadnet-nextjs.vercel.app
- GitHub: https://github.com/Devesh223/broadnet-website
